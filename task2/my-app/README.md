## LAB 5 - Task 2 React TS project
In this task I created User Search components using TypeScript. I used User interface from Task 1 and created typed state with useState<User[]>.
I used generics because TypeScript cannot always understand array type automatically. I also typed event handlers using React.ChangeEvent<HTMLInputElement> and React.Mouse.Event<HTMLButtonElement> instead of any.
The input filters users by name and shows "No results found" in list is empty.

In this lab I learned how to type state and events correctly and why TypeAcript is more safe than normal JS.
