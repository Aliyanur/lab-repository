## Rendering Methods

### SSG (Static Site Generation)
Pages are created at build time.  
This makes the site very fast.

### ISR (Incremental Static Regeneration)
Pages update every 60 seconds automatically.  
This helps keep data fresh.

## Pages
- Home page (SSG + ISR)
- Post page (Dynamic SSG)

## Conclusion
SSG is good for blogs because it is fast and simple.  
ISR helps update content without rebuilding the whole app.
