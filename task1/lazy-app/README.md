# Lab 7.1 – Code Splitting with Suspense

In this lab I create small dashboard app with routing.
Home page load normal.
Dashboard, Settings and Profile load using lazy().

Code splitting means app is divided into small parts.
It helps improve performance because user download only needed page.

lazy() load component dynamic.
Suspense show loading spinner while page is loading.

I learn how to use lazy and Suspense to make app faster.
